# 데이터 마케터 포트폴리오

가족이 운영하는 지역 한식 매장의 네이버 광고 운영 사례를 정리한 신입 데이터 마케터 포트폴리오입니다.

- 사이트: https://jjony553.github.io/data-marketer/
- 매장명·지역 등 매장을 특정할 수 있는 정보는 비공개 처리했습니다.

## 구성

| 구분 | 섹션 | 내용 |
| --- | --- | --- |
| 통합 | 01 타임라인 · 02 3개월 추이 | 9.29 광고 시작부터 11.25까지의 실행 순서, 10월·11월 나란히 비교, 스마트플레이스 일평균 추이 |
| PART 1 · 10월 | 03 ~ 06 | 매출 +61%, 키워드 3갈래 전략, 유입 채널·키워드, 광고비 업종 비교·기기별 효율 |
| PART 2 · 11월 | 07 ~ 09 | 11월 광고 보고서(매체·요일·연령·성별), 대표 이미지 1·2차 테스트, 블로그 체험단·릴스·클립·자체 블로그 |
| PART 3 · 다음 단계 | 10 ~ 11 | 데이터 신호별 개선 액션, 운영 리듬과 12월 이후 로드맵 |

상단 성과 카드는 `통합 / 10월 / 11월` 탭으로 기간을 바꿔 볼 수 있습니다.

## 자료 기준

- 네이버 스마트플레이스 리포트: 9월·10월, 11월 1~12일 반영분 (2026년 11월 13일 캡처)
- 네이버 광고 캠페인 보고서: 2026년 11월 1~25일 성별·연령대별 CSV 2종 (총계 대조 후 사용)
- 매장 제공 총매출: 2026년 10월 전년 동월 대비
